# Rasbhav Books એકસાથે ચકાસવાની રીત

આ યાદી હાલની વાચક, લેખક અને એડમિન સુવિધાઓ માટે છે. તમારા ટેસ્ટ ખાતાં અને નમૂનાનું પુસ્તક વાપરો.

## વેબસાઇટ ખોલો

Codespacesમાં પ્રોજેક્ટના ટર્મિનલમાં આ આદેશો એક પછી એક ચલાવો.

```sh
git pull --ff-only
npm install
npm run dev:all
```

ટર્મિનલ ચાલુ રાખો. **Ports** ટૅબમાં **5173** સામેની લિંક ખોલો. નીચેના દરેક પેજનું સરનામું એ જ લિંકના અંતે લગાડવાનું છે. જો સાઇટ ખૂલે પણ લૉગિન કે પુસ્તકો લોડ કરવામાં ભૂલ આવે, તો બીજા ટર્મિનલમાં `curl -i http://localhost:4000/api/v1/health` ચલાવો. API માટે `200 OK` અને ડેટાબેઝ માટે `"database":"connected"` દેખાવું જોઈએ.

## ત્રણ ખાતાંથી ચકાસો

| કયું ખાતું | શું કરવું | શું દેખાવું જોઈએ |
| --- | --- | --- |
| વાચક | `/login` ખોલો, વાચકનું લૉગિન પસંદ કરો અને લૉગિન કરો. | સામાન્ય લૉગિન પેજ પર વાચક અને લેખકની પસંદગી હોય. એડમિન માટે અલગ સરનામું હોય. |
| વાચક | એક પુસ્તક વિશલિસ્ટમાં ઉમેરો. `/wishlist` પરથી Discover ખોલો. `/account`માં નામ અને વાંચનના શોખ બદલીને પેજ ફરી ખોલો. | Discover હોમપેજના પુસ્તકો સુધી લઈ જાય. ખાતામાં તમારી સાચવેલી વિગતો દેખાય. |
| લેખક | મંજૂર થયેલા લેખક તરીકે `/author/login` પરથી પ્રવેશ કરો અને `/author/books`માં ડ્રાફ્ટ બનાવો. પુસ્તકના ભાવમાં ₹49.75 લખો, વિગતો સાચવો અને ડ્રાફ્ટ ફરી ખોલો. | લેખકે લખેલો ભાવ દેખાય. કવર અને PDF અપલોડ કરવા ખાનગી R2 સ્ટોરેજ અને ClamAV સ્કેનર તૈયાર હોવાં જોઈએ. |
| લેખક | પુસ્તકની ભાષામાં શીર્ષક, ઓછામાં ઓછા 40 અક્ષરનું વર્ણન, કવર અને PDF સાથે પુસ્તક સમીક્ષા માટે મોકલો. | ડ્રાફ્ટ સમીક્ષા માટે મોકલાયેલો દેખાય. |
| એડમિન | અલગ બ્રાઉઝર પ્રોફાઇલમાં `/admin/login` ખોલીને એડમિન ખાતા અને MFAથી પ્રવેશ કરો. `/admin/author-books`માં આ પુસ્તક ખોલો. | લેખકનો ₹49.75નો ભાવ દેખાય. એડમિન વિગતો અને ભાવ મંજૂર કરી શકે અથવા નોંધ સાથે પુસ્તક પાછું મોકલી શકે. |
| લેખક અને એડમિન | પ્રથમ વખત ભાવ બદલવાની નોંધ સાથે પુસ્તક પાછું મોકલો. લેખક ભાવ બદલીને ફરી મોકલે, પછી એડમિન નવી રજૂઆત ખોલીને મંજૂર કરે. | લેખકને નોંધ દેખાય અને નવી રજૂઆતમાં નવો ભાવ દેખાય. મંજૂરી પછી પણ પુસ્તકનું જાહેર પ્રકાશન બંધ રહે. |

બીજા ટેસ્ટ ડ્રાફ્ટનો ભાવ ૦ રાખીને સમીક્ષા માટે મોકલો. એડમિનની યાદીમાં તેનો ભાવ **મફત (₹૦)** દેખાવો જોઈએ. આ ફક્ત ભાવની સમીક્ષા છે; rights wording મંજૂર થાય ત્યાં સુધી પુસ્તક જાહેર રીતે પ્રકાશિત થતું નથી.

વાચક ખાતાથી `/library` પણ ખોલો. હાલ publishing rights gate ચાલુ હોવાથી અહીં ખાલી લાઇબ્રેરી દેખાવું સ્વાભાવિક છે. મફત અથવા ખરીદેલું પુસ્તક મંજૂર અને ઉપલબ્ધ થયા પછી તે અહીંથી વાંચી શકાશે.\n\nમોબાઇલની પહોળાઈએ પણ લૉગિન, ડ્રાફ્ટમાં ભાવ અને એડમિનની મંજૂરીનાં બટન વાપરી જુઓ. કોઈ તકલીફ આવે તો પેજનું સરનામું, કયું ખાતું વાપર્યું અને દેખાયેલો ભૂલ સંદેશ નોંધો.

## ચુકવણીની ચકાસણી

હાલ વાચકો માટે ખરીદી બંધ છે. GitHubની **Quality checks**માં **Check signed book payments against a MongoDB replica set** નામની ચકાસણી અલગ ટેસ્ટ ડેટાબેઝમાં ચાલે છે. એ ખોટી સહીવાળી સૂચના નકારે છે અને સાચી ચુકવણીની સૂચના ફરી આવે ત્યારે પણ એક જ હિસાબી નોંધ બને છે તે તપાસે છે. લાઇવ ખરીદી શરૂ થયા પછી વાચકનો ખરીદીથી પુસ્તક વાંચવા સુધીનો માર્ગ પણ ચકાસવાનો રહેશે.
